# 전체 진행 경로 시뮬레이션 결과 (2026-09-29)

`npm run playthrough -- 365`로 생성한 측정 결과와 그 해석이다. 생성 기준 코드는 이 문서가 들어 있는 커밋이다(콘텐츠 수치가 바뀌면 다시 생성할 것). 도구 설계와 정책 가정은 DECISIONS.md D044.

## 핵심 관찰 (측정값 — 조정 여부는 별도 결정)

1. **왕국 복원과 장비 갖추기가 매우 빠르다.** 11구역 복원은 상시 접속 9.8시간 / 1시간마다 확인 2.6일, 철 도구 전부·밭 3칸·축사 2단계·동물 종별 3마리·금 장신구 3개까지 9.1일 / 20.6일. 그 뒤로는 Lv99 반복만 남는다(채집 계열 51~118일, 제작 계열 200~290일).
2. **패시브 스킬이 액티브보다 훨씬 빨리 만렙이 된다.** 목장 Lv99 5.6일 / 12.0일, 농사 Lv99 10.3일 / 19.4일. 액티브 채집 스킬은 50일 이상, 제작 스킬은 200일 이상 걸린다.
3. **재봉 Lv99는 사실상 도달 불가.** 모든 재봉 레시피가 양털을 쓰고 양털 공급은 양 3마리 최대 하루 96개다. 1년 뒤 재봉 Lv69~70이며, 가장 효율 좋은 마법 의복(양털 6개·경험치 500)으로 Lv70→99에 필요한 경험치(약 5,341만)를 채우려면 약 18년이 걸린다. 재봉 도구(구리·철)와 마법탑 복원·축사 2단계도 양털 대기가 가장 긴 병목이다.
4. **골드가 금방 의미를 잃는다.** 누적 획득 골드가 3일차 약 270만 G(1시간 확인 130만 G), 1년 6억~11억 G인데 가장 큰 골드 지출은 금 장신구 30,000 G다. 경제 업적(누적 100만 G)은 3일 안팎에 모두 달성된다. 장비를 다 갖춘 뒤의 골드 지출은 동물 사료 구매뿐이다.
5. **1시간마다 확인하는 플레이에서 마법이 늦다.** 마법 Lv70에 333일이 걸려 1년 안에 만렙이 안 된다(상시 접속은 212일에 Lv99). 마법부여석 약초를 밭 3칸에서 사료 작물과 나눠 기르는 것이 원인으로 보이나, 봇 정책(가장 낮은 스킬 우선 훈련)의 영향일 수도 있다.

## 발견된 게임 쪽 문제 — 수정됨(D045)

- **자동 파종/수확을 설치하면 작물을 바꿀 수 없던 문제.** 밭 칸마다 "비우기"를 추가했다(다 자란 칸은 먼저 수확, 자라는 칸은 작물·비료가 사라짐). 시뮬레이션도 자동 파종을 설치하고 칸 비우기로 작물을 바꾸며, 1시간 확인 기준 장비 완비가 34.2일 → 20.6일, 1년 뒤 Lv99 스킬이 6개 → 10개로 늘었다.
- **왕국 공사 완료 판정과 저장 검증의 불일치(잠재).** 오차 범위 안에서 단계를 완료하면 진행량을 기간 값으로 맞춘다.

## 조정 후보 (제안만 — 승인 전 구현하지 않음)

- 양털 공급 또는 재봉 레시피의 양털 소모량 재조정(예: 재봉 경험치 대비 양털 소모 완화, 축사 단계 추가).
- 골드 소모처 추가 또는 후반 판매가·마일스톤 보상 재검토.
- 패시브 경험치 곡선 재조정(D032 이후에도 액티브 대비 10배 가까이 빠름).
- 중반 구간(장비 완비~Lv99) 사이의 목표 추가 — 현재 상시 접속 9일 이후 목표가 만렙뿐이다.

## 보고서 원문

- 새 저장에서 실제 게임 엔진 함수만 호출하는 플레이 정책(봇)으로 365일을 진행한 측정값입니다(D044). 최적 플레이나 확정 밸런스가 아닙니다.
- 목표 순서: 왕국 11구역 복원(구역이 연 스킬의 돌 도구 포함) → 장신구·도구 티어·밭/축사·동물·길드 → 전 스킬 Lv99.
- 정책 가정: 음식·비료·일일 퀘스트·환전 미사용. 원재료 구매는 첫 씨앗과 동물 사료(밭이 못 따라갈 때)만. 골드가 모자라면 목표에 쓰이지 않는 보유품을 팔고, 그래도 모자라면 시간당 판매가가 가장 높은 원재료를 채집해 판다. 목표가 밭·동물을 기다리는 동안에는 가장 낮은 채집 스킬을 올린다.
- 자동 파종/수확을 설치하며(농사 Lv25), 필요한 작물이 어느 칸에도 없으면 필요 없는 작물 칸을 비우고 바꿔 심는다(D045).
- "1시간마다 확인"은 1시간 간격으로만 결정하며, 지금 작업이 먼저 끝나면 남는 시간을 채울 채집을 다음 작업으로 예약한다.
