## 해석

1. **장신구가 후반 목표가 됐다:** 이전에는 장신구가 게임 초반 2주 안에 끝났다. 이제 청금(대장작업 Lv65)·별철(Lv80)·태양(Lv95) 재질과 신화·고대·태초 등급이 레벨 격자에 맞춰 열리고, 최상위 등급 확률이 10% 이하라 원하는 옵션을 맞추는 일이 끝까지 남는다. 시뮬레이션 봇은 세 슬롯을 모두 태양 재질까지 올렸다.
2. **진행 속도:** 옵션 최대치가 올라 전체가 상시 약 6%, 1시간 확인 약 11% 빨라졌다(분석 때 예상한 약 10%와 같은 범위). 시드 간 편차도 줄었다.
3. **골드·마력 결정:** 후반 승급 비용(10만·30만·100만 G)과 부여석 재료로 후반 마력 결정의 소비처가 늘었다. 만렙까지 누적 골드는 상시 4.9억, 1시간 확인 6.6억 G 수준이다(시드 1).
