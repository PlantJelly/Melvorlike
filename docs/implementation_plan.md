# 멜버라이크 왕국 재건 - 8차 마일스톤 (밸런스 및 편의성 개선)

치트 버튼 덕분에 한계점 테스트를 아주 훌륭하게 해주셨습니다! 레벨이 무한정 올라가는 방치형 게임의 특성상, 덧셈/뺄셈 방식의 수식을 쓰면 확률이 100%를 돌파하거나 소요 시간이 마이너스(-)가 되는 치명적인 버그가 발생합니다.

기획자님의 6가지 피드백을 모두 반영하여 게임의 수학적 밸런스와 편의성을 영구적으로 바로잡는 **[8차 마일스톤]**을 제안합니다.

## User Review Required

### 1. 소요 시간 계산식 변경 (마이너스 시간 방지)
- **문제**: 현재 "기본 시간 - (감소율%)" 방식이라 강화가 높아지면 시간이 0 이하나 음수가 됩니다.
- **해결 (점근선 수식 적용)**: 소요 시간을 `기본 시간 / (1 + 속도 증가율)` 공식으로 변경합니다.
  - 이렇게 하면 속도 증가율이 +100%면 시간이 절반(50%)이 되고, +900%면 10분의 1(10%)이 되므로 **아무리 레벨이 무한정 올라도 절대 시간이 0이나 음수가 되지 않습니다.**
  - 추가 안전장치로 **게임 내 최소 작업 시간을 무조건 0.1초(100ms)**로 강제 하드캡(Hard Cap)을 씌웁니다.

### 2. 확률형 옵션의 상한선(Cap) 적용
- **문제**: 절약, 캐시백 등의 확률이 240% 등 100%를 초과하는 문제.
- **해결**: [풍요], [절약], [하도급], [캐시백] 등 퍼센트(%) 기반 확률형 옵션은 계산 결과가 아무리 높아도 **최대 100%를 넘지 않도록 제한(Max Cap)**합니다. 

### 3. 영지 건물 개편 (재료 소모 및 표시)
- **문제**: 골드만 소모하고, 감소율 표기가 100%를 넘어도 강화가 무한정 됨.
- **해결**: 
  - 영지 건물 업그레이드 시 **골드뿐만 아니라 관련 기본 재료(나무, 돌, 물고기, 주괴 등)를 함께 요구**하도록 변경합니다.
  - 시간 감소(-%) 표기 대신, 위 1번 수식에 맞춰 **"작업 효율(속도) +X% 상승"**으로 직관적으로 표기를 바꿉니다.

### 4. 편의성 및 UI 수정
- **길드 상점**: 총 14개로 늘리고, 상단(특가 매입 7개) / 하단(특가 판매 7개) 2줄로 UI를 분리하여 깔끔하게 정렬합니다.
- **장비 강화 선택**: `[풍요]` 라는 이름만 나오는 대신, 드롭다운에서 `[풍요] 결과물 2배 획득 (선택 시 증가치)` 처럼 직관적인 옵션 설명이 함께 나오도록 수정합니다.
