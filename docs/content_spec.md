# 콘텐츠 상세 스펙 (v1)

> [!NOTE]
> `game_design.md`가 원칙/구조 문서라면, 이 문서는 거기서 정한 구조에 맞춰 **구체적인 숫자와 목록**을 채운 것입니다. 전부 초안이라 밸런스 테스트 후 조정 예정.

## 1. 대장작업 — 업그레이드 재료

새 공식 설계 불필요. 기존 건물 강화 공식을 그대로 재사용:
- 골드 비용 = `baseCostGold * 1.3^level`
- 재료 비용 = `baseCostAmt * 1.5^(level % 10)`
- 재료 티어 = `min(3, floor(level / 10))` (10레벨마다 한 단계씩 상위 재료로 전환)
- 왕국 시설 강화(D048)가 이 공식을 12단계에 맞춰 쓴다: 골드 60,000×1.3^단계, 재료 20×1.5^(단계%3), 3단계마다 재료 티어 전환, 단계당 해당 스킬 속도 +3%, 단계 1~8은 스킬 Lv(8n), 9~12단계는 Lv76·90·94·98 필요(D052, 이전 72·80·88·96).

## 2. 요리 레시피 (6종)

| 이름 | 재료 | 효과 | 지속시간 | 해금 |
|---|---|---|---|---|
| 구운 생선 | 피라미 x2 | 낚시 속도 +10% | 10분 | 요리 Lv1 |
| 야채죽 | 감자 x2, 당근 x1 | 전 스킬 채집 속도 +5% | 15분 | 요리 Lv1 |
| 달걀찜 | 달걀 x2 | 경험치 획득 +10% | 10분 | 요리 Lv10 |
| 나무꾼 도시락 | 감자 x1, 당근 x1, 구운생선 x1 | 벌목 속도 +15% | 15분 | 요리 Lv15 |
| 광부의 스튜 | 우유 x1, 당근 x2 | 채광 속도 +15% | 15분 | 요리 Lv15 |
| 대장장이 정식 | 달걀 x2, 감자 x1, 우유 x1 | 대장작업 속도 +15% | 15분 | 요리 Lv25 |
| 축제 요리 | 위 재료 각 1개씩 | 전 스킬 속도 +10% | 20분 | 요리 Lv40 |

- 버프는 **비활성 스택 없음**(같은 계열 버프는 갱신만, 중첩 안 됨) — 버프 관리가 복잡해지는 것 방지
- 낚시 속도 버프처럼 "채광의 스튜"류는 대장작업 효율에는 안 붙게, 스킬별로 명확히 분리

## 3. 목장 — 동물/사료 (3종)

| 동물 | 해금 | 구매가 | 사료 | 주기 | 산출물 |
|---|---|---|---|---|---|
| 닭 | 목장 Lv1 | 500골드 | 밀 x5 | 30분 | 달걀 |
| 양 | 목장 Lv15 | 2,000골드 | 밀 x10 | 45분 | 양털 (재봉 의복 재료) |
| 소 | 목장 Lv30 | 5,000골드 | 당근 x2 | 60분 | 우유 |

- 소 사료는 원안 당근 x10이 우유 판매가보다 비싸 x2로 조정했다(D043, 임시값).
- 사료가 떨어지면 생산이 멈춤(알림 표시), 방치해도 손해는 없고 그냥 "쉬는" 상태 — 페널티성 손실 없음
- 목장 레벨업 시 최대 사육 마릿수 증가 (건물처럼 골드+재료 강화)

## 4. 농사 — 작물 목록

**작물씨 (요리 재료)**: 밀(Lv1) → 감자(Lv10) → 당근(Lv25) → 황금옥수수(Lv40)
**약초씨 (마법 재료)**: 캐모마일(Lv1) → 쑥(Lv10) → 마법쑥(Lv25) → 신비허브(Lv40)
**나무묘목**: 기존 벌목 자원 티어 그대로 재사용 (나무/참나무/단단한나무/마법나무 묘목) — 새 아이템 체계 만들지 않음

**비료 3종** (구매형 소모품, 시장에서 골드 구매):
- 속성비료: 성장 시간 -X%
- 배양비료: 수확량 2배 확률 +X%
- 회수비료: 씨앗 소모 없이 파종할 확률 +X%

## 5. 길드

**일일퀘스트** (3개 로테이션, 매일 갱신): "자원 N개 납품" 형태, 보상 = 골드 + 길드 경험치
**1회성 마일스톤 퀘스트** (예시 10개, 온보딩 가이드 역할 겸함):
1. 아무 자원이나 처음 채집하기
2. 아무 스킬이나 Lv10 달성
3. 첫 장비 제작
4. 첫 요리 제작
5. 목장에 동물 첫 입주
6. 농사 첫 수확
7. 길드 환전소 첫 이용
8. 아무 스킬이나 Lv50 달성
9. 마법부여석 첫 제작
10. 왕국 구역 첫 복원

**환전소 비율**: 한 티어 내려갈 때마다 수량 x1.5배 (2티어 내려가면 x2.25 복리)
**환전 깊이 제한**: 길드 Lv1~9는 1티어까지, Lv10~19는 2티어까지, Lv20+는 3티어까지 환전 가능

## 6. 주 도구 — 해금 레벨

새로 설계할 필요 없음. 기존 `EquipmentTiers`의 `reqLevel`(스톤=1, 구리=10, 철=30, 금=50)을 그대로 재사용 — 주 도구는 스킬 시작(Lv1)부터 장착 가능하고, 상위 재질만 레벨로 순차 해금.

## 7. 장신구 — 마법부여석 리롤 등급 확률

재질 상한 규칙(§4.2) 위에서, 마법부여석 등급별 실제 리롤 확률:

| 마법부여석 등급 | 하급 | 중급 | 상급 | 영웅 | 전설 | 신화 | 고대 | 태초 |
|---|---|---|---|---|---|---|---|---|
| 스톤급 | 70% | 30% | - | - | - | - | - | - |
| 구리급 | 40% | 35% | 25% | - | - | - | - | - |
| 철급 | 25% | 25% | 25% | 25% | - | - | - | - |
| 금급 | 15% | 20% | 25% | 25% | 15% | - | - | - |
| 청금급 | 10% | 15% | 20% | 25% | 20% | 10% | - | - |
| 별철급 | 5% | 10% | 15% | 20% | 20% | 20% | 10% | - |
| 태양급 | 5% | 10% | 15% | 20% | 20% | 15% | 10% | 5% |

후반 재질(D054): 청금(대장작업 Lv65, 상한 신화)·별철(Lv80, 고대)·태양(Lv95, 태초). 옵션 최대치 신속 12→14·16·18%, 지혜 18→21·24·27%, 흥정 30→35·40·45%. 후반 부여석은 마법 Lv65·80·95에서 같은 단계 약초 2 + 마나석 + 상급·최상급·원초 마력 결정으로 만든다.

(장신구 재질 상한을 초과하는 등급은 애초에 풀에서 제외 — 예: 스톤 장신구에 철급 마법부여석을 쓰더라도 상급 이상은 안 나옴)

## 8. 도감/수집 — 미정

확률 정착민 초안은 채택하지 않는다. 작업 중 희귀 영구 보너스를 얻는 구조가 멜버의 스킬링 펫과 역할상 너무 가깝고, 왕국의 필수 진행을 확률에 묶을 수 있기 때문이다. 아이템·레시피·복원 기록을 활용한 수집 목표는 전체 생산망을 만든 뒤 별도로 설계한다.

## 9. 업적 (분류별 예시)

- **성장형**: 각 스킬 Lv10/30/50/70/99 달성 (보상: 소량 영구 보너스)
- **수집형**: 아이템·레시피·복원 기록 수집 (구체 단계와 보상 미정)
- **경제형**: 누적 골드 획득 100만/1,000만/1억 (보상: 환전소 비율 개선) — 구현 수치(D051, 후반 수입에 맞춰 1만/10만/100만에서 상향)
- **제작형**: 장신구 첫 전설 등급 리롤 성공 (보상: 마법부여석 제작 비용 할인)
- **완주형**: 전 스킬 만렙, 왕국 완전 복원, 수집·업적 달성 (보상 미정)

모든 업적 보상은 반드시 실질 효과(버프/할인/해금) 동반 — 단순 체크마크 없음.

## 10. 스킬 시너지 체인 (전체 다이어그램)

```
벌목 --(묘목)--> 농사(나무묘목) --(수확)--> 벌목 보너스 [순환]
채광 --(광맥 보너스: 마나석)--> 마법 --(마법부여석)--> 장신구
농사(작물씨) --> 요리 --> 전 스킬 버프
농사(약초씨) --> 마법 재료
낚시 --> 요리 재료
목장(사료=농사 작물) --> 요리 재료(달걀/우유)
대장작업 --> 주 도구 + 장신구 기본형 (전 스킬 효율 기반)
야외 채집 --> 목공/조제/재봉 공용 재료 (재봉은 섬유가 주 재료, 양털은 의복에 1개 — D046)
목공 --> 복원용 판자/들보 + 시설 부품
조제 --> 접착제/보존제/염료/비료 + 제작 보조재
재봉 --> 밧줄/천/침구/돛/깃발 + 복원 자재
길드 --> 전체를 관통하는 가이드 + 환전 허브
왕국 복원 --> 스킬/구역/시설 해금 --> 생산망 확장
```

## 11. 온보딩과 구역 해금 방향

신규 저장은 벌목·채광만 열린다. 첫 대장간 프로젝트를 통해 `조사 → 폐허 정리 → 자재 납품 → 복원 공사 → 대장작업 해금`을 배운다. 그 뒤 부서진 다리(낚시), 무너진 식당(요리), 길드 회관(길드), 버려진 밭(농사), 낡은 축사(목장), 쓰러진 마법탑(마법) 같은 구역 중 일부를 선택해 복원하는 분기형 구조로 확장한다.

이전 저장은 현재 이용 가능한 모든 스킬과 시설을 유지한다. 대응 프로젝트는 보상 재지급 없이 완료 처리한다.

## 11-1. 레벨 디자인 격자 (D049)

- 액티브 스킬의 재료·레시피 해금: Lv1·10·20·30·40·50·65·80·95 (50까지 10단위, 이후 15단위, 최종 재료 Lv95).
- 도구(제작): Lv1 돌 · 5 구리 · 15 철 · 25 은 · 35 마나강철 · 45 수정 · 58 금 · 72 청금 · 84 별철 · 92 미스릴 · 97 태양 — 재료 해금 사이에 배치(D052에서 별철 88 → 84, 미스릴·태양 추가, 최대 +97%).
- 후반 해금 보강(D052): Lv80 이후 레벨당 시간이 길어 해금을 시간 간격 기준으로 둔다 — Lv72 이후 72·76·80·84·87·90·92·94·95·97·98(도구·시설 강화 단계·재료). Lv87 단계: 오로라나무·미스릴 광석·청새치(폭풍 해역)·이슬꽃, 오로라 목재·미스릴 주괴·이슬꽃 탕약·이슬 비단·청새치 구이(제작 6종 +15% 45분)·찬란한 마력 결정, 오로라나무 묘목(농사 Lv85). 시설 조건은 Lv80과 같은 6단계.
- Lv65·80·95 재료·레시피는 해당 구역 시설 4·6·8단계 필요.
- 새 채집 재료: 벌목 소나무·자작나무·달빛나무·별빛나무·세계수 가지 / 채광 은 광석·수정 원석·청금석·별철 광석·태양석 / 낚시 메기·송어·장어·철갑상어·참치·황금 잉어 / 채집 쐐기풀·아마·은빛 이끼·비단 덩굴·요정 꽃.
- 새 제작: 목공 판자·목재 5종, 조제 탕약·기름·정수·향유·영약, 재봉 쐐기풀 직물·아마포·침구·비단·왕국 깃발, 대장작업 은·마나강철·수정 합금·청금·별철·태양 주괴, 요리 생선 요리 6종(음식 효과는 D050에서 추가), 마법 마력 결정 5종(상위 도구 재료).
- 농사 후반(D050): Lv55 호박·월광초, Lv70 황금 밀·불꽃풀, Lv85 왕실 포도·세계수 잎(Lv70·85는 밭 시설 4·6단계). 새 나무 5종 묘목(농사 Lv25·40·55·70·85).
- 목장 후반(D050): Lv45 염소(염소젖), Lv60 알파카(알파카 털), Lv75 꿀벌(벌꿀), Lv90 황금 거위(황금알)(Lv75·90은 축사 시설 4·6단계).
- 새 생선 요리 6종은 음식 효과가 있다(메기 매운탕 채광·대장작업 +10% … 황금 잉어찜 전 스킬 +12% 60분).
- 수치는 공식으로 정한 임시값(D049·D050).

## 12. 후반 편의 기능

여러 스킬을 동시에 생산하는 자동 채집 장치는 넣지 않는다. 레벨·시설 보상으로 아래 편의 기능을 단계적으로 검토한다.

- 선택한 작업 반복
- 목표 수량에서 자동 정지
- 다음 작업 하나 예약
- 자주 쓰는 작업·장비 프리셋

이 기능들은 전역 액티브 슬롯 하나를 그대로 사용하며 시간당 생산량 자체를 늘리지 않는다.

## 13. 첫 왕국 프로젝트 — 폐허가 된 대장간

| 단계 | 내용 |
|---|---|
| 조사 | 즉시 실행, 정리 작업과 복원 요구사항 공개 |
| 폐허 정리 | 기본 작업량 30초, 완료 시 나무 3개·돌 4개 확정 회수 |
| 자재 납품 | 나무 12개·돌 10개, 일부 납품 가능 |
| 복원 공사 | 기본 작업량 45초 |
| 완료 | 대장작업 영구 해금, 왕국 복원도 1 |

수치는 첫 수직 슬라이스 검증용 임시값이다. 프로젝트는 만료되거나 실패하지 않고, 작업을 바꾸거나 중지해도 정리·복원 진행도와 납품량이 보존된다.
