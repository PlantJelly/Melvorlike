# 콘텐츠 상세 스펙 (v1)

> [!NOTE]
> `game_design.md`가 원칙/구조 문서라면, 이 문서는 거기서 정한 구조에 맞춰 **구체적인 숫자와 목록**을 채운 것입니다. 전부 초안이라 밸런스 테스트 후 조정 예정.

## 1. 대장작업 — 업그레이드 재료

새 공식 설계 불필요. 기존 건물 강화 공식을 그대로 재사용:
- 골드 비용 = `baseCostGold * 1.3^level`
- 재료 비용 = `baseCostAmt * 1.5^(level % 10)`
- 재료 티어 = `min(3, floor(level / 10))` (10레벨마다 한 단계씩 상위 재료로 전환)

## 2. 요리 레시피 (6종)

| 이름 | 재료 | 효과 | 지속시간 | 해금 |
|---|---|---|---|---|
| 구운 생선 | 피라미 x2 | 낚시 속도 +10% | 10분 | 요리 Lv1 |
| 야채죽 | 감자 x2, 당근 x1 | 전 스킬 채집 속도 +5% | 15분 | 요리 Lv1 |
| 달걀찜 | 달걀 x2 | 경험치 획득 +10% | 10분 | 요리 Lv10 |
| 나무꾼 도시락 | 감자 x1, 당근 x1, 구운생선 x1 | 벌목 속도 +15% | 15분 | 요리 Lv15 |
| 광부의 스튜 | 우유 x1, 당근 x2 | 채광 속도 +15% | 15분 | 요리 Lv15 |
| 대장장이 정식 | 달걀 x2, 감자 x1, 우유 x1 | 대장작업 속도 +15% | 15분 | 요리 Lv25 |
| 축제 요리 | 위 재료 각 1개씩 | 전 스킬 속도 +10% | 20분 | 요리 Lv40 |

- 버프는 **비활성 스택 없음**(같은 계열 버프는 갱신만, 중첩 안 됨) — 버프 관리가 복잡해지는 것 방지
- 낚시 속도 버프처럼 "채광의 스튜"류는 대장작업 효율에는 안 붙게, 스킬별로 명확히 분리

## 3. 목장 — 동물/사료 (3종)

| 동물 | 해금 | 구매가 | 사료 | 주기 | 산출물 |
|---|---|---|---|---|---|
| 닭 | 목장 Lv1 | 500골드 | 밀 x5 | 30분 | 달걀 |
| 양 | 목장 Lv15 | 2,000골드 | 밀 x10 | 45분 | 양털 (고가 판매용) |
| 소 | 목장 Lv30 | 5,000골드 | 당근 x10 | 60분 | 우유 |

- 사료가 떨어지면 생산이 멈춤(알림 표시), 방치해도 손해는 없고 그냥 "쉬는" 상태 — 페널티성 손실 없음
- 목장 레벨업 시 최대 사육 마릿수 증가 (건물처럼 골드+재료 강화)

## 4. 농사 — 작물 목록

**작물씨 (요리 재료)**: 밀(Lv1) → 감자(Lv10) → 당근(Lv25) → 황금옥수수(Lv40)
**약초씨 (마법 재료)**: 캐모마일(Lv1) → 쑥(Lv10) → 마법쑥(Lv25) → 신비허브(Lv40)
**나무묘목**: 기존 벌목 자원 티어 그대로 재사용 (나무/참나무/단단한나무/마법나무 묘목) — 새 아이템 체계 만들지 않음

**비료 3종** (구매형 소모품, 시장에서 골드 구매):
- 속성비료: 성장 시간 -X%
- 배양비료: 수확량 2배 확률 +X%
- 회수비료: 씨앗 소모 없이 파종할 확률 +X%

## 5. 길드

**일일퀘스트** (3개 로테이션, 매일 갱신): "자원 N개 납품" 형태, 보상 = 골드 + 길드 경험치
**1회성 마일스톤 퀘스트** (예시 10개, 온보딩 가이드 역할 겸함):
1. 아무 자원이나 처음 채집하기
2. 아무 스킬이나 Lv10 달성
3. 첫 장비 제작
4. 첫 요리 제작
5. 목장에 동물 첫 입주
6. 농사 첫 수확
7. 길드 환전소 첫 이용
8. 아무 스킬이나 Lv50 달성 (자동화 해금 시점과 겹침)
9. 마법부여석 첫 제작
10. 도감(정착민) 첫 등록

**환전소 비율**: 한 티어 내려갈 때마다 수량 x1.5배 (2티어 내려가면 x2.25 복리)
**환전 깊이 제한**: 길드 Lv1~9는 1티어까지, Lv10~19는 2티어까지, Lv20+는 3티어까지 환전 가능

## 6. 주 도구 — 해금 레벨

새로 설계할 필요 없음. 기존 `EquipmentTiers`의 `reqLevel`(스톤=1, 구리=10, 철=30, 금=50)을 그대로 재사용 — 주 도구는 스킬 시작(Lv1)부터 장착 가능하고, 상위 재질만 레벨로 순차 해금.

## 7. 장신구 — 마법부여석 리롤 등급 확률

재질 상한 규칙(§4.2) 위에서, 마법부여석 등급별 실제 리롤 확률:

| 마법부여석 등급 | 하급 | 중급 | 상급 | 영웅 | 전설 |
|---|---|---|---|---|---|
| 스톤급 | 70% | 30% | - | - | - |
| 구리급 | 40% | 35% | 25% | - | - |
| 철급 | 25% | 25% | 25% | 25% | - |
| 금급 | 15% | 20% | 25% | 25% | 15% |

(장신구 재질 상한을 초과하는 등급은 애초에 풀에서 제외 — 예: 스톤 장신구에 철급 마법부여석을 쓰더라도 상급 이상은 안 나옴)

## 8. 정착민 (도감 대체 시스템) — 예시 9종

| 정착민 | 획득 조건 | 보너스 |
|---|---|---|
| 늙은 나무꾼 | 벌목 중 낮은 확률 | 벌목 속도 +2% |
| 광산 십장 | 채광 중 낮은 확률 | 채광 속도 +2% |
| 뱃사공 | 낚시 중 낮은 확률 | 낚시 속도 +2% |
| 떠돌이 대장장이 | 대장작업 중 낮은 확률 | 대장작업 속도 +2% |
| 요리사 견습생 | 요리 중 낮은 확률 | 버프 음식 지속시간 +10% |
| 목동 | 목장 산출 중 낮은 확률 | 사료 소모량 -5% |
| 농부의 딸 | 농사 수확 중 낮은 확률 | 수확량 +1개 확률 |
| 방랑 마법사 | 마법부여석 제작 중 낮은 확률 | 마법부여석 제작 재료 -10% |
| 길드 서기 | 길드 퀘스트 완료 낮은 확률 | 환전소 비율 소폭 개선 |

전부 소소한 수치라 "완주 목표"로서 부담 없이 수집 가능 — 파워 인플레이션 방지.

## 9. 업적 (분류별 예시)

- **성장형**: 각 스킬 Lv10/30/50/70/99 달성 (보상: 소량 영구 보너스)
- **수집형**: 정착민 3/6/9명 등록 (보상: 시장 할인율)
- **경제형**: 누적 골드 획득 1만/10만/100만 (보상: 환전소 비율 개선)
- **제작형**: 장신구 첫 전설 등급 리롤 성공 (보상: 마법부여석 제작 비용 할인)
- **완주형**: 전 스킬 만렙, 도감(정착민) 100%, 전 업적 달성 (보상: 칭호 + 특수 코스메틱)

모든 업적 보상은 반드시 실질 효과(버프/할인/해금) 동반 — 단순 체크마크 없음.

## 10. 스킬 시너지 체인 (전체 다이어그램)

```
벌목 --(묘목)--> 농사(나무묘목) --(수확)--> 벌목 보너스 [순환]
채광 --(광맥 보너스: 마나석)--> 마법 --(마법부여석)--> 장신구
농사(작물씨) --> 요리 --> 전 스킬 버프
농사(약초씨) --> 마법 재료
낚시 --> 요리 재료
목장(사료=농사 작물) --> 요리 재료(달걀/우유)
대장작업 --> 주 도구 + 장신구 기본형 (전 스킬 효율 기반)
길드 --> 전체를 관통하는 가이드 + 환전 허브
```

## 11. 온보딩 순서 (최종 확정)

벌목·채광(동시 시작) → 대장작업(도구 제작 필요성 부여) → 낚시 → 요리(첫 크래프팅+버프 소개) → 길드(정식 가이드 도입, 마일스톤 퀘스트로 지금까지 배운 것 복습) → 농사 → 목장 → 마법(엔드게임 진입)

## 12. 후반 자동화 조건

각 액티브 스킬 **레벨 50 달성 시**, 길드 시장에서 "자동 채집 장치"를 골드로 구매해 해당 스킬 자동화 해금 (스킬별 개별 해금, 한 번 사면 영구).
