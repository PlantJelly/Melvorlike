# 성장 곡선 기준 분석 — 2026-09-14

`npm run simulate`가 현재 콘텐츠 데이터와 엔진 경험치 공식을 직접 읽어 만드는 첫 기준선이다. 이 문서는 그 결과에서 확인된 설계 문제와 다음 조정 방향을 기록한다. 콘텐츠 수치가 바뀌면 최신 값은 CLI 출력을 우선한다.

## 계산 범위

- 각 레벨에서 시간당 경험치가 가장 높은 해금 자원을 선택한다.
- 무도구, 레벨 요구만 만족하면 도구를 즉시 장착하는 경우, 속도 음식 10%, 경험치 장신구 18%를 차례로 비교한다.
- 가공 재료와 사료는 충분히 공급된다고 가정한다. 도구 제작 재료를 모으는 시간도 포함하지 않는다.
- 생산량과 판매가는 입력 재료·씨앗 비용을 빼지 않은 총량이다. 농사는 실제 수확 반환량 3개를 반영한다.
- 따라서 결과는 완주 예상 시간이 아니라 각 스킬 자체의 이론상 성장 속도를 비교하는 기준값이다.

## 첫 결과

| 구간 | 무도구 | 해금 도구+음식 10%+경험치 18% |
| --- | ---: | ---: |
| 벌목 Lv10 | 3.0분 | 2.0분 |
| 마법 Lv10 | 5.0분 | 3.3분 |
| 벌목 Lv99 | 19.3일 | 9.4일 |
| 낚시 Lv99 | 36.4일 | 17.6일 |
| 농사 Lv99 | 2,294일 | 1,111일 |
| 목장 Lv99 | 7,708일 | 3,733일 |

액티브 스킬은 Lv99가 대략 9~18일 범위에 모이지만, 패시브 스킬은 같은 경험치 곡선을 사용하면서 한 번의 경험치 지급 주기가 수분~1시간이라 수년 단위로 벌어진다. 반대로 액티브 스킬 Lv10은 3~5분이라 레벨 해금만으로 초반 진행을 조절하기에는 지나치게 빠르다.

실제 레시피와 도구 비용을 펼친 무도구 생산 경로는 다음과 같다. 상위 도구는 요구 레벨까지 올리는 시간을 제외한 재료 작업 기준이다.

| 목표 | 원재료·가공 작업 시간 |
| --- | ---: |
| 돌 도구 1개 | 51초 |
| 구리 도구 1개 | 2.5분 |
| 철 도구 1개 | 5.5분 |
| 구운 생선 1개 | 12초 |

첫 도구와 첫 요리가 현재 데이터만으로는 1분 안팎에 끝난다. 화면 전환과 선택 시간을 고려해도 10~20분짜리 첫 목표를 만들기에는 간격이 부족하므로, 온보딩 작업에서 목표 재료량과 행동 마일스톤을 함께 조정해야 한다.

## 권장 조정 순서

1. 전역 경험치 공식을 먼저 바꾸지 않는다. 액티브 후반은 현재도 비교 가능한 범위에 있고, 전역 공식을 바꾸면 모든 스킬이 함께 흔들린다.
2. 농사와 목장은 다중 플롯·동물 마릿수 확장 설계를 먼저 정한 뒤 경험치를 조정한다. 병렬 생산량이 늘어날 예정이므로 현재 한 칸·한 마리 기준 숫자만 올리면 확장 후 과도하게 빨라질 수 있다.
3. 초반은 레벨 요구만 늘리기보다 도구 제작, 첫 요리, 길드 마일스톤 같은 실제 행동 조건으로 해금을 나눈다.
4. 다음 확장에서는 레벨업에 필요한 작업과 골드 구매를 생산 경로에 결합한다. 그 결과로 첫 도구·첫 요리·농사·목장·마법 진입 목표 시간을 조정한다.

이 기준선에서는 실제 게임 수치를 변경하지 않는다. 수치 조정은 패시브 확장 방식과 목표 플레이 시간을 정한 뒤 별도 기능 브랜치에서 진행한다.

## 적용된 조정 — 2026-09-16 (`feature/balance-passive-skills`)

전체 방향 문서의 액티브 10개 로드맵이 완결된 뒤(D030), 사용자 요청으로 "전체 생산망 밸런스 조정"을 진행하며 위 1번 항목(패시브 스킬 경험치 곡선)을 먼저 처리했다. 다중 플롯/마릿수 확장은 여전히 미구현·미결정 상태이므로 2번 항목은 그대로 보류하고, 밭 1칸·동물종당 1마리라는 현재 제약 위에서만 수치를 조정했다 — 확장이 실제로 추가되면 이 경험치 곡선을 다시 검토해야 한다.

방법: 성장/사육 주기(`baseDurationMs`)와 전역 경험치 공식은 그대로 두고(1번 항목 원칙 유지), 액티브 10개 스킬의 레시피 없는 순수 채집 자원만 골라 reqLevel별 시간당 경험치·판매가 평균을 구했다(Lv1≈26,683/hr, Lv10≈40,418/hr, Lv30≈67,632/hr, Lv50≈112,727/hr — 판매가는 Lv1≈1,503G/hr, Lv10≈2,927G/hr, Lv30≈6,488G/hr, Lv50≈13,818G/hr). 농사(Lv1/10/25/40)·목장(Lv1/15/30)의 reqLevel은 이 네 기준점 사이를 로그선형 보간해 목표 시간당 경험치·판매가를 정하고, `exp = 목표시간당경험치 × (baseDurationMs/3600000)`(판매가도 동일한 방식)로 역산해 반올림했다.

| 스킬 | 목표 | 조정 전 | 조정 후 |

| 농사 | Lv.10 | 2.5시간 | 4.0분 |
| 농사 | Lv.50 | 9.3일 | 3.1시간 |
| 농사 | Lv.99 | 2,294.0일 | 26.5일 |
| 목장 | Lv.10 | 12.5시간 | 30.0분 |

Lv99 기준 농사·목장이 다른 10개 스킬의 무도구 Lv99 군집(17.4일~36.4일)에 정확히 들어온다. 목장 Lv10(30분)은 이 군집의 3~5분보다 여전히 느린데, 목장 자체가 최하위 티어(달걀)부터 30분 주기라 이 정도 격차는 "check back 주기가 긴 패시브 스킬"이라는 설계 의도와 부합한다고 판단해 남겨뒀다(성장/사육 주기를 바꾸지 않는다는 1번 원칙과 상충하므로).

기존 요리/마법/재봉 레시피가 농사·목장 산출물을 재료로 쓰는 곳(예: `blacksmith_meal`의 달걀/감자/우유, `enchant_stone_stone`의 캐모마일)의 판매가는 함께 조정하지 않았다 — 완제품 판매가가 원재료 재조정으로 상대적으로 낮아졌지만, 이 레시피들은 되팔기가 아니라 소모(버프/제작)가 목적이라 원재료 대비 완제품 판매가 역전 자체는 기존 제작 스킬(예: 광석→주괴)에도 이미 있던 패턴이다. 골드 경제 전반(도구/길드/장신구 비용 대비 획득 속도)과 완제품 판매가 정합성은 이번 라운드 범위 밖으로 남겨뒀다.
