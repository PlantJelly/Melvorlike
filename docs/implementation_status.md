# 구현 현황 — 농사·목장 산출물 요리 연결 (2026-09-11)

## 실제 구현
- 벌목, 채광, 벽돌·구리/철 주괴 제작, 재료 보관 및 1개/10개 판매.
- 낚시터 3곳: 마을 개울(피라미 Lv1), 갈대 호수(붕어 Lv10), 상류 여울(연어 Lv30).
- 요리 8종: 생선 3종(구운 생선 낚시+10%/10분, 민물 생선탕 벌목·채광·낚시+5%/15분, 훈제 연어 대장작업+15%/15분) + 농사·목장 재료 5종(아래 참고).
- 스킬별 돌/구리/철 도구 제작 및 즉시 적용. 낚싯대·조리도구·괭이·사료통 포함.
- 음식은 한 종류만 적용. 같은 음식 1개/5개 사용 시 지속시간 연장. 다른 음식은 UI에서 남은 효과 폐기 안내 후 교체. 자동 섭취는 없음.
- 전체 화면에서 현재 작업, 진행률, 음식 효과, 밭·목장 상태와 남은 시간 표시.
- 순수 데이터 엔진으로 경과 시간 일괄 정산. 음식 만료 전후를 구분해 계산하며 재료 부족 시 제작 중단.
- **농사(패시브) 최소 루프**: 작물 3종(밀 Lv1, 감자 Lv10, 당근 Lv25)을 골드로 구매 → 밭 1칸에 파종(씨앗 1개 소모) → 액티브 작업·화면 이동·접속 종료와 무관하게 경과 시간만큼 성장 → 다 자라면 수확 버튼으로 같은 작물 3개 회수 + 농사 경험치. 다 자란 뒤에는 수확 전까지 더 진행되지 않는다. 자동 파종/수확과 비료는 아직 없음.
- **목장(패시브) 최소 루프**: 동물 3종(닭 Lv1/500G, 양 Lv15/2,000G, 소 Lv30/5,000G)을 골드로 구매하면 즉시 사육 시작(영구, 재구매 없음). 사료(닭·양=밀, 소=당근)가 있으면 접속 여부와 무관하게 주기마다(30/45/60분) 자동으로 산출물(달걀/양털/우유) 1개를 만들고 사료를 소비 — 수확 같은 수동 확정 동작 없음. 사료가 없으면 주기 1회분에서 진행을 멈추고 대기(적체·손해 없음), 사료를 채우면 다음 정산에서 바로 재개. 여러 동물을 동시에 사육 가능, 서로 독립 진행. 마릿수 상한·비료류 육성 보조 아이템은 아직 없음(동물종당 1마리).
- **농사·목장 → 요리 연결(이번 작업)**: 감자·당근(농사)과 달걀·우유(목장)를 재료로 쓰는 요리 5종 추가. 기존 재료/저장/버프 엔진을 그대로 재사용(엔진 코드 변경 없음, 콘텐츠 데이터만 추가):
  - 야채죽(요리 Lv1, 감자2+당근1): 전 스킬 속도 +5%, 15분
  - 나무꾼 도시락(요리 Lv15, 감자1+당근1+구운생선1): 벌목 속도 +15%, 15분
  - 광부의 스튜(요리 Lv15, 우유1+당근2): 채광 속도 +15%, 15분
  - 대장장이 정식(요리 Lv25, 달걀2+감자1+우유1): 대장작업 속도 +15%, 15분
  - 축제 요리(요리 Lv40, 감자1+당근1+달걀1+우유1+구운생선1): 전 스킬 속도 +10%, 20분(최상위 레시피)
  - "전 스킬" 효과는 액티브 스킬뿐 아니라 농사·목장(패시브)에도 그대로 적용됨을 브라우저에서 직접 확인.
  - 기획서(content_spec.md)의 달걀찜(경험치 획득 +10%)은 구현하지 않음 — 현재 음식 시스템은 스킬별 속도 배율만 지원하고 경험치 배율 개념이 없어, 새 버프 타입을 추가하는 별도 작업이 필요하다고 판단(DECISIONS.md D009).
- 두 패시브 스킬(농사/목장)은 액티브 단일 작업 슬롯과 별개로 항상 병행 진행되며, 스킬 레벨/도구 체계를 그대로 재사용한다(전용 도구도 자동으로 제작 가능).
- 버전 5 저장: 인벤토리, 도구, 진행 중 작업과 부분 진행, 음식 효과, 밭 상태, 목장 사육 상태(동물별 진행량) 포함. 이번 작업은 콘텐츠 추가만이라 저장 버전 변경 없음.
- v1~v4 저장 이전 지원: 기존 스킬/재료/도구 유지, 요리·농사·목장 Lv1 추가(각 버전 미만은 해당 데이터 없음), v2 작업 시간 단위를 v3+ 작업량으로 변환.
- 손상된 저장은 자동 저장을 중단하여 원본 보호. 여러 탭 동시 플레이 충돌 방지는 미구현(개발 중 실제로 배경 탭의 자동저장이 다른 탭의 저장을 덮어쓰는 사례를 직접 목격).

## 임시 밸런스 및 기획과 차이
- 구리는 채광/제련 Lv1, 철은 Lv10 해금. 주괴 연료는 현재 목재. 석탄 보너스/광맥은 미구현.
- 다음 레벨 경험치: 100 × 1.12^(레벨-1), 최대 레벨 99. 기존 저장의 현재 레벨 요구 경험치는 다음 레벨업까지 유지.
- 도구는 돌 +15%, 구리 +35%, 철 +65% 작업 속도. 금 도구는 후속 콘텐츠. 농사·목장 도구도 같은 표를 재사용하며 성장/산출 속도에 곱연산으로 적용된다.
- 도구는 재료를 사용하는 즉시 제작이며 제작 경험치는 없음. 대장작업 경험치는 가공으로 획득.
- 음식과 도구의 속도 보너스는 합산. 속도가 변해도 작업/밭/목장 진행률은 보존.
- 오프라인 시간 상한은 현재 없음. PC 시계의 경과 시간을 사용하며 역행 시 추가 지급하지 않음.
- 낚시는 우선 확정 획득. 꽝/미끼 시스템 없음.
- 농사 씨앗은 "구매 = 파종 재료" 하나의 아이템으로 단순화(멜버식 별도 종자 아이템 없음). 수확량은 작물 불문 3개 고정. 밭은 1칸만 존재하며 다중 플롯, 자동 파종/수확, 비료 3종은 기획 초안에 있으나 미구현. 요리 재료로도 쓰이기 시작했으므로, 씨앗/식재료 소비가 재파종 여유분에 미치는 영향은 아직 플레이테스트되지 않음.
- 목장 산출량은 동물 불문 주기당 1개 고정. 동물종당 1마리만 사육 가능(마릿수 상한/증축은 기획 초안에 있으나 미구현). 양털은 기획서대로 요리 재료로 쓰이지 않고 판매 전용으로 남김.
- 새 스킬은 현재 처음부터 표시. 점진적 해금 온보딩은 후속 작업.

## 미구현
마법/장신구, 길드/환전, 광맥/석탄, 정착민, 업적, 저장 내보내기/복구 UI, 농사 비료·다중 플롯·자동화, 목장 마릿수 상한·비료류 보조 아이템, 경험치 배율형 음식 효과(달걀찜).
기획서의 확정 표현과 별개로, 제안만 된 기능과 수치는 추가 검토 대상.

## 검증
- 테스트 53개 통과: 기존 수식/생산/저장/음식/농사/목장 47개 + 농사·목장 요리 연결 6개(야채죽의 패시브 스킬 적용 포함 신규 레시피 5종 각각의 제작→섭취→버프 적용 확인, 기존 생선 레시피 보존 확인).
- 음식 만료를 포함한 긴 시간 일괄 정산과 짧은 틱의 동일성, 진행률 보존, 재료 부족, 적용 대상, 음식 중첩 방지, 저장 이전, 재접속 중복 지급 방지.
- 첫 생산 루프 브라우저 검증: 벌목 → 돌 채집 → 벽돌 → 돌 도끼. 새로고침 후 재료/도구와 속도 효과 보존 확인.
- 낚시/요리 브라우저 검증: 피라미 → 구운 생선 → 섭취로 낚시 시간 3.5초→3.2초. 새로고침 후 작업/효과 복원, 보관함에서 5개 사용 시 50분 연장 및 재고 차감 확인.
- 농사 브라우저 검증: 밀 씨앗 구매 → 심기 → 다른 탭 이동 후에도 진행률 증가 → 새로고침 후 진행률 유지 → 다 자란 뒤 수확 → 보관함 판매 확인 → 도구 제작 탭에 농사(괭이) 카드 자동 등록 확인. 도구 장착 후 잔여 시간 표시가 속도를 반영하는지도 확인.
- 목장 브라우저 검증: 닭 구매 → 사료 보유 상태로 실시간 경과 후 주기 완료 시 산출·사료 소비·경험치 확인(저장 데이터 직접 대조) → 사료 부족/재개 확인 → 보관함 판매·도구 자동 등록 확인.
- 농사·목장 요리 연결 브라우저 검증(2026-09-11): 요리 Lv40·재료 보유 상태로 시드 → 요리 탭에 신규 5종이 기존 3종과 함께 정확한 재료/효과로 표시 확인 → 야채죽 제작(감자2·당근1 소비) → 섭취 후 전역 상태에 "전 스킬 속도 +5%" 표시 확인 → 모든 요리 카드의 소요시간이 정확히 5% 단축됨을 확인(요리 자체 포함) → 농사 탭에서 밀·감자·당근 성장 시간도 동일 비율로 단축됨을 확인(패시브 스킬까지 "전 스킬" 버프가 적용됨을 실증).
