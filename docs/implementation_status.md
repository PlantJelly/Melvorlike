# 구현 현황 — 첫 생산 루프 (2026-09-11)

## 구현
- 벌목, 채광, 벽돌·구리/철 주괴 제작, 재료 보관 및 1개/10개 판매.
- 스킬별 돌/구리/철 도구 제작 및 즉시 적용. 도구는 영구 보존.
- 전체 화면에서 현재 작업/진행률 표시, 화면을 바꿔도 작업 유지.
- 순수 데이터 엔진으로 경과 시간 일괄 정산. 재료 부족 시 제작 중단.
- 버전 2 저장: 인벤토리, 도구, 진행 중 작업과 부분 진행 포함. 버전 1의 골드/스킬 이전 지원.
- 손상된 저장을 읽으면 자동 저장을 중단하여 원본 보호. 여러 탭 동시 플레이 충돌 방지는 아직 미구현.

## 임시 밸런스 및 기획과 차이
- 첫 루프를 검증하기 위해 구리는 채광/제련 Lv1, 철은 Lv10 해금.
- 주괴 연료는 현재 목재. 석탄 보너스/광맥은 미구현.
- 다음 레벨 경험치: 100 × 1.12^(레벨-1), 최대 레벨 99. 기존 저장의 현재 레벨 요구 경험치는 다음 레벨업까지 유지.
- 도구는 돌 +15%, 구리 +35%, 철 +65% 작업 속도. 금 도구는 후속 콘텐츠.
- 도구 제작은 재료를 사용하는 즉시 제작이며 제작 경험치는 없음. 대장작업 경험치는 가공으로 획득.
- 오프라인 시간 상한은 현재 없음. PC 시계의 경과 시간을 사용하며 역행 시 추가 지급하지 않음.

## 미구현
낚시, 농사/목장, 요리, 마법/장신구, 길드/환전, 광맥/석탄, 정착민, 업적, 저장 내보내기/복구 UI.
기획서의 확정 표현과 별개로, 제안만 된 기능과 수치는 추가 검토 대상.

## 검증
- 수식 6개 + 생산/저장 8개 테스트 통과, 빌드 통과.
- 긴 시간 일괄 정산과 짧은 틱의 동일성, 재료 부족, 레벨 제한, 최초 도구 제작, 재접속 중복 지급 방지, 시계 역행, 저장 검증, 판매 검증.
- 브라우저 직접 검증: 벌목 → 돌 채집 → 벽돌 제작 → 돌 도끼 제작. 재료 부족 자동 중지, 새로고침 후 재료/도구 보존 및 벌목 시간 3.0초→2.6초 확인.
