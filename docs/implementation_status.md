# 구현 현황 — 낚시·요리 순환 (2026-09-11)

## 실제 구현
- 벌목, 채광, 벽돌·구리/철 주괴 제작, 재료 보관 및 1개/10개 판매.
- 낚시터 3곳: 마을 개울(피라미 Lv1), 갈대 호수(붕어 Lv10), 상류 여울(연어 Lv30).
- 요리 3종: 구운 생선(낚시 +10%, 10분), 민물 생선탕(벌목/채광/낚시 +5%, 15분), 훈제 연어(대장작업 +15%, 15분).
- 스킬별 돌/구리/철 도구 제작 및 즉시 적용. 낚싯대·조리도구 포함.
- 음식은 한 종류만 적용. 같은 음식 1개/5개 사용 시 지속시간 연장. 다른 음식은 UI에서 남은 효과 폐기 안내 후 교체. 자동 섭취는 없음.
- 전체 화면에서 현재 작업, 진행률, 음식 효과와 남은 시간 표시.
- 순수 데이터 엔진으로 경과 시간 일괄 정산. 음식 만료 전후를 구분해 계산하며 재료 부족 시 제작 중단.
- 버전 3 저장: 인벤토리, 도구, 진행 중 작업과 부분 진행, 음식 효과 포함.
- v1/v2 저장 이전 지원: 기존 스킬/재료/도구 유지, 요리 Lv1 추가, v2 작업 시간 단위를 v3 작업량으로 변환.
- 손상된 저장은 자동 저장을 중단하여 원본 보호. 여러 탭 동시 플레이 충돌 방지는 미구현.

## 임시 밸런스 및 기획과 차이
- 구리는 채광/제련 Lv1, 철은 Lv10 해금. 주괴 연료는 현재 목재. 석탄 보너스/광맥은 미구현.
- 다음 레벨 경험치: 100 × 1.12^(레벨-1), 최대 레벨 99. 기존 저장의 현재 레벨 요구 경험치는 다음 레벨업까지 유지.
- 도구는 돌 +15%, 구리 +35%, 철 +65% 작업 속도. 금 도구는 후속 콘텐츠.
- 도구는 재료를 사용하는 즉시 제작이며 제작 경험치는 없음. 대장작업 경험치는 가공으로 획득.
- 음식과 도구의 속도 보너스는 합산. 속도가 변해도 작업 진행률은 보존.
- 오프라인 시간 상한은 현재 없음. PC 시계의 경과 시간을 사용하며 역행 시 추가 지급하지 않음.
- 낚시는 우선 확정 획득. 꽝/미끼 시스템 없음.
- 생선탕/훈제 연어는 농사·목장 구현 전 테스트용 레시피. 기존 작물/축산 요리 초안을 확정 대체하지 않음.
- 새 스킬은 현재 처음부터 표시. 점진적 해금 온보딩은 후속 작업.

## 미구현
농사/목장, 마법/장신구, 길드/환전, 광맥/석탄, 정착민, 업적, 저장 내보내기/복구 UI.
기획서의 확정 표현과 별개로, 제안만 된 기능과 수치는 추가 검토 대상.

## 검증
- 테스트 25개 통과: 기존 수식/생산/저장 14개 + 음식/저장 이전/콘텐츠 11개.
- 음식 만료를 포함한 긴 시간 일괄 정산과 짧은 틱의 동일성, 진행률 보존, 재료 부족, 적용 대상, 음식 중첩 방지, 저장 이전, 재접속 중복 지급 방지.
- 첫 생산 루프 브라우저 검증: 벌목 → 돌 채집 → 벽돌 → 돌 도끼. 새로고침 후 재료/도구와 속도 효과 보존 확인.
- 낚시/요리 브라우저 검증: 피라미 → 구운 생선 → 섭취로 낚시 시간 3.5초→3.2초. 새로고침 후 작업/효과 복원, 보관함에서 5개 사용 시 50분 연장 및 재고 차감 확인.
