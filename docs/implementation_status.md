# 구현 현황 — 세이브 백업/복원 (2026-09-12)

## 실제 구현
- 벌목, 채광, 벽돌·구리/철/금 주괴 제작, 재료 보관 및 1개/10개 판매.
- 낚시터 3곳: 마을 개울(피라미 Lv1), 갈대 호수(붕어 Lv10), 상류 여울(연어 Lv30).
- 요리 8종: 생선 3종(구운 생선 낚시+10%/10분, 민물 생선탕 벌목·채광·낚시+5%/15분, 훈제 연어 대장작업+15%/15분) + 농사·목장 재료 5종(야채죽/나무꾼 도시락/광부의 스튜/대장장이 정식/축제 요리).
- 스킬별 돌/구리/철 도구 제작 및 즉시 적용. 낚싯대·조리도구·괭이·사료통·마법봉 포함.
- 음식은 한 종류만 적용. 같은 음식 1개/5개 사용 시 지속시간 연장. 다른 음식은 UI에서 남은 효과 폐기 안내 후 교체. 자동 섭취는 없음.
- 전체 화면에서 현재 작업, 진행률, 음식 효과, 밭·목장 상태와 남은 시간 표시.
- 순수 데이터 엔진으로 경과 시간 일괄 정산. 음식 만료 전후를 구분해 계산하며 재료 부족 시 제작 중단.
- **농사(패시브) 최소 루프**: 작물 3종(밀 Lv1, 감자 Lv10, 당근 Lv25)을 골드로 구매 → 밭 1칸에 파종(씨앗 1개 소모) → 액티브 작업·화면 이동·접속 종료와 무관하게 경과 시간만큼 성장 → 다 자라면 수확 버튼으로 같은 작물 3개 회수 + 농사 경험치. 다 자란 뒤에는 수확 전까지 더 진행되지 않는다.
- **목장(패시브) 최소 루프**: 동물 3종(닭 Lv1/500G, 양 Lv15/2,000G, 소 Lv30/5,000G)을 골드로 구매하면 즉시 사육 시작(영구). 사료(닭·양=밀, 소=당근)가 있으면 접속 여부와 무관하게 주기마다(30/45/60분) 자동 산출·사료 소비. 사료 부족 시 주기 1회분에서 대기, 채우면 즉시 재개.
- 농사·목장 → 요리 연결: 감자·당근·달걀·우유를 재료로 쓰는 요리 5종. "전 스킬" 효과는 패시브 스킬(농사/목장)에도 그대로 적용됨.
- **길드 — 원재료 구매/환전**:
  - 원재료 구매: 가공품(recipe 있는 아이템)이 아닌 모든 아이템(나무/돌/광석/생선/작물/축산물)을 스킬 레벨로 이미 해금했다면 골드로 즉시 구매 가능(`buy` 가격, 판매가의 5배). 기존 농사 "씨앗 구매"도 동일 함수 사용으로 통합(`buyCrop`→`buyResource` 일반화, 스킬 레벨 검증을 엔진 단에도 추가 — 이전엔 UI에서만 막고 있었음).
  - 원재료 환전: 상위 티어 원재료(참나무/단단한나무/마법나무/철광석/붕어/연어)를 같은 스킬의 최하위(Lv1) 재료로 환전. 티어 차이 1단계당 1.5배씩 복리(내림) 적용 — 예: 단단한나무(2단계 차이) 4개 → 나무 9개.
  - 길드 등급: 3단계(초급→중급 3,000G→상급 15,000G, 골드만 소모). 등급이 오를수록 환전 가능한 티어 차이가 늘어남(1→2→3단계). 퀘스트(일일/마일스톤)는 미구현 — 길드 레벨업은 후원(골드 지불)으로 단순화.
  - 순환 거래 방지: 환전은 항상 스킬 최하위 재료로만 향하고(역방향 경로 없음), 모든 환전 항목이 "환전 후 되팔기"가 "직접 팔기"보다 항상 손해가 되도록 설계·테스트됨.
  - 상세 설계 근거는 DECISIONS.md D010 참고.
- **마법부여·장신구**:
  - 공급 루프: 농사 약초 4종(캐모마일/쑥/마법쑥/신비 허브), 채광 마나석·금 광석, 대장작업 금 주괴를 재료로 마법 스킬에서 스톤/구리/철/금급 마법부여석 제작.
  - 공용 장신구 3슬롯(개척자의 왕관/장인의 목걸이/풍요의 반지). 슬롯마다 하나만 스톤 재질로 제작하며 구리→철→금으로 승급. 승급은 기존 옵션과 희귀도를 그대로 유지한다.
  - 리롤: 현재 장신구 재질 이상 등급의 마법부여석 1개를 사용해 옵션 1개(전 스킬 속도/경험치/판매가)와 희귀도(하급~전설)를 교체. 재질 상한 밖 희귀도는 확률 풀에서 제외하고 나머지를 재정규화한다.
  - 장신구 효과는 시간 정산·경험치·판매 엔진에 적용되며 세 슬롯 효과는 합산한다. 확률은 사용자 리롤 순간에만 사용하므로 온라인/오프라인 생산 정산은 결정론을 유지한다.
  - 비용/옵션 수치와 직접 채광 마나석은 임시 설계. 상세 근거는 DECISIONS.md D011 참고.
- **세이브 백업/복원**: 설정 화면에서 현재 저장 전체를 JSON 파일로 내려받거나 클립보드에 복사할 수 있고(다운로드 시 브라우저가 저장 위치를 물어보는 대화상자는 브라우저 자체 동작이라 앱에서 제어할 수 없어 클립보드 복사를 대안으로 제공), 파일을 선택해 저장을 되돌릴 수 있다. 복원 전 확인을 거치며, `decodeSave`로 먼저 검증에 성공한 파일만 적용된다(버전·형식이 잘못된 파일은 기존 저장을 건드리지 않고 오류 메시지만 표시). 저장 손상으로 자동 저장이 중단된 상태(`blocked`)도 유효한 백업을 복원하면 자동 저장이 다시 시작된다. 복원은 `advance()`로 백업 시점 이후 경과 시간을 정산해 밀린 생산을 안내에 반영한다. 저장에는 체크섬(FNV-1a, 키 정렬 후 해시)이 함께 저장되어 값을 하나라도 바꾼 뒤 그대로 복원을 시도하면 거부된다 — 단, 암호학적 보안이 아니라 텍스트 편집기로 값을 슬쩍 바꾸는 것을 막는 수준의 마찰이며, 체크섬이 없던 v7 이전 저장은 그대로 허용된다(하위 호환). 저장 스키마 버전은 그대로 v7(체크섬은 게임 상태가 아닌 저장 파일 봉투 개념이라 버전을 올리지 않음). 설계 근거는 DECISIONS.md D012·D013 참고.
- 두 패시브 스킬(농사/목장)은 액티브 단일 작업 슬롯과 별개로 항상 병행 진행되며, 스킬 레벨/도구 체계를 그대로 재사용한다.
- 버전 7 저장: 인벤토리, 도구, 진행 중 작업과 부분 진행, 음식 효과, 밭 상태, 목장 사육 상태, 길드 등급, 마법 스킬/도구와 장신구 3슬롯 포함.
- v1~v6 저장 이전 지원: 기존 데이터 유지, 버전별로 없던 요리·농사·목장·길드·마법/장신구 기본값 추가.
- 손상된 저장은 자동 저장을 중단하여 원본 보호. 여러 탭 동시 플레이 충돌 방지는 미구현(개발 중 실제로 목격).

## 임시 밸런스 및 기획과 차이
- 구리는 채광/제련 Lv1, 철은 Lv10 해금. 주괴 연료는 현재 목재. 석탄 보너스/광맥은 미구현.
- 다음 레벨 경험치: 100 × 1.12^(레벨-1), 최대 레벨 99.
- 도구는 돌 +15%, 구리 +35%, 철 +65% 작업 속도. 농사·목장 도구도 같은 표를 재사용.
- 음식과 도구의 속도 보너스는 합산. 속도가 변해도 작업/밭/목장 진행률은 보존.
- 오프라인 시간 상한은 현재 없음.
- 낚시는 우선 확정 획득. 꽝/미끼 시스템 없음.
- 농사 씨앗은 "구매 = 파종 재료" 하나의 아이템. 밭은 1칸만 존재. 목장은 동물종당 1마리만.
- 길드 환전은 항상 "그 스킬의 Lv1 재료"로만 향함(예: 철광석→돌, 구리광석 아님). 임의의 두 티어 사이 환전(예: 단단한나무→참나무)은 미구현 — content_spec.md의 N×N 환전표 대신 단순화된 "최하위로 수렴" 규칙.
- 길드 레벨업은 퀘스트가 아닌 골드 후원으로 단순화(기획서는 퀘스트+자재 소모). 일일퀘스트/마일스톤퀘스트(온보딩 겸용)는 미구현.
- 새 스킬은 현재 처음부터 표시. 점진적 해금 온보딩은 후속 작업.
- 마법부여석 재료인 마나석은 광맥 발견 이벤트가 아직 없어 채광 Lv30 직접 자원으로 임시 제공. 장신구 옵션은 슬롯당 1개이며 세 슬롯이 같은 옵션 풀을 공유한다.
- 장신구 제작/승급 비용과 옵션 수치는 플레이테스트 전 임시값. 상한을 넘는 희귀도 확률을 버리지 않고 남은 가중치로 재정규화한다.

## 미구현
길드 퀘스트(일일/마일스톤), 장신구 다중 옵션/고유 옵션 풀, 광맥/석탄, 정착민, 업적, 만렙까지 시간 시뮬레이션, 다중 탭 저장 충돌 방지, 농사 비료·다중 플롯·자동화, 목장 마릿수 상한·비료류 보조 아이템, 경험치 배율형 음식 효과(달걀찜).
