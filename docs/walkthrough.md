# 8차 마일스톤 완료 보고서 (수식 밸런스 및 UX 패치)

> [!IMPORTANT]
> 레벨이 무한정 올라가도 게임 시스템이 붕괴되지 않도록 수학적인 한계선(Cap)과 수식을 재설계했습니다.

## 1. 마이너스 시간 방지 및 하드캡
- 작업 속도 공식이 `1 / (1 + 상승률)` 점근선 수식으로 변경되었습니다.
- 이제 건물 레벨과 장비 강화 레벨이 아무리 높아져서 +900% 상승률을 기록하더라도 시간이 음수가 되지 않고 10분의 1로 줄어듭니다.
- 게임 내 최소 작업 시간이 **0.1초(100ms)** 미만으로 떨어지지 않도록 절대 하드캡이 적용되었습니다.

## 2. 확률형 옵션 100% 상한
- [절약] 재료 비소모, [풍요] 2배 획득 등의 확률 계산 결과값이 100%를 초과하더라도 실제 확률 적용 및 UI 표시에서는 **최대 100%**까지만 적용되도록 제한되었습니다.

## 3. 영지 건물 개편
- 건물을 업그레이드할 때 더 이상 골드만으로 불가능합니다.
  - 제재소: 나무 소모
  - 채석장: 돌 소모
  - 낚시터: 피라미 소모
  - 대장간: 돌 벽돌 소모
- 시간 감소 표기가 "작업 속도 상승 +X%"로 직관적으로 변경되었습니다.

## 4. UI 및 편의성
- **길드 상점**: 길드 상점의 특가 상품이 정확히 **구매 7개, 판매 7개**로 분리되어 좌우로 깔끔하게 표시됩니다.
- **장비 강화**: 전설 확정 부여 시, 드롭다운에서 각 옵션이 어떤 효과를 주는지 자세한 설명이 함께 출력됩니다.
